# Customer Behavior Analysis Dashboard

## Overview

This project analyzes retail customer shopping behavior to identify purchasing trends, customer segments, and revenue patterns. The insights are presented through an interactive Power BI dashboard.

## Tools Used

Python | Pandas | SQL | Power BI

## Project Steps

* Data cleaning and preprocessing using Python (Pandas)
* SQL queries to analyze revenue, customer segments, and purchasing patterns
* Interactive dashboard creation in Power BI

## Key Insights

* Clothing category generates the highest revenue
* Young adults contribute the most purchases
* Majority of customers are non-subscribers
* Returning customers drive consistent sales

## Dashboard

Interactive visualizations include:

* Total customers, average purchase, and ratings
* Revenue by category
* Sales by age group
* Subscription insights
