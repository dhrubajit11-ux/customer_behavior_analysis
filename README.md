# 📌 Overview

This project analyzes **retail customer shopping behavior** to identify:

- 🛒 Purchasing Trends
- 👥 Customer Segments
- 💰 Revenue Patterns
- 📊 Shopping Insights

The analysis is visualized through an interactive **Power BI Dashboard** designed to uncover meaningful business insights from customer transaction data.

---

# 🎯 Project Objectives

✅ Analyze customer purchasing behavior  
✅ Identify high-revenue product categories  
✅ Segment customers based on shopping patterns  
✅ Study subscription behavior  
✅ Build an interactive business intelligence dashboard
